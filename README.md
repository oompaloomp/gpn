# GPN (Газпромнефть Цены)

Парсер цен на топливо с сайта Газпромнефти для станций Перми.

## Описание

Скрипт автоматически получает актуальную информацию о ценах и наличии топлива на всех станциях Газпромнефти в Перми:
- Бензин 92, 95
- Премиум бензины G-92, G-95, G-100
- Дизельное топливо

## Установка

```bash
git clone https://github.com/oompaloomp/gpn.git
cd gpn
pip install -r requirements.txt
```

## Запуск

```bash
python GPN_INFO_v3.py
```

## Пример вывода

```
⛽️ Пермь Газпромнефть (Берег Камы) АЗС N 508 (10:34)

🔴 92 — нет
🔴 95 — нет
🔴 G-95 — нет
🟢 Дизель — 81.36 ₽
```

## Особенности

- 🎯 Умная фильтрация по ключевым словам для избежания дубликатов из других регионов
- 🔄 Автоматическое управление сессией и cookies
- 📍 Поддержка 15+ станций в Перми
- ⚡ Быстрый парсинг через curl
